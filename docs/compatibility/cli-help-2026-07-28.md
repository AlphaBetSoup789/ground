# CLI invocation-surface check — 2026-07-28

This is a narrow, credential-free compatibility observation for Ground 0.1.0. It
does not certify authenticated runs or streamed event formats.

## Observed help surface

Version and help commands were run locally without sending a model prompt:

- Codex `exec --help` exposed JSON Lines output, sandbox selection, color
  selection, repository-check control, and native `exec resume`.
- Claude Code `--help` exposed print mode, `stream-json`, partial-message
  streaming, verbose output, permission modes, and session resume.
- Gemini CLI `--help` exposed headless prompt mode, `stream-json`, plan and
  auto-edit approval modes, and session resume.

These flags match Ground’s current recognized-runtime argv construction. Ground’s
unit suite separately covers argv stripping, Ask/Agent mode mapping, cancellation,
bounded output, session-ID parsing, representative normalized events, and resume
construction.

## Not certified by this check

- No authenticated or paid model request was made.
- No filesystem or command action was requested from a CLI.
- The representative JSON event fixtures were not captured from these exact
  installed versions.
- Windows and Linux invocation behavior was not exercised.

Before calling these versions supported, capture redacted event fixtures from
disposable accounts and repositories, review each vendor’s telemetry and
permission behavior, and run the full compatibility report described in
[Compatibility](../COMPATIBILITY.md).
