## Observed help surface

Version and help commands were run locally without sending a model prompt:

- Codex `exec --help` exposed JSON Lines output, sandbox selection, color
  selection, repository-check control, and native `exec resume`.
- Claude Code `--help` exposed print mode, `stream-json`, partial-message
  streaming, verbose output, permission modes, and session resume.
- Gemini CLI `--help` exposed headless prompt mode, `stream-json`, plan and
  auto-edit approval modes, and session resume.
- The installed Antigravity CLI 1.0.9 exposed headless prompt mode and native
  conversation resume, but not a structured output flag.

The first three help surfaces match Ground’s current recognized-runtime argv
construction. Ground’s unit suite separately covers argv stripping, Ask/Agent mode
mapping, cancellation, bounded output, session-ID parsing, representative
normalized events, and resume construction. Those Codex, Claude, and Gemini
versions are named by the executable
[synthetic parser fixtures](../../fixtures/compatibility/README.md); Antigravity
is pinned separately to the reviewed 1.1.8 release below.

  [headless-mode contract](https://antigravity.google/docs/cli/headless).

| Reviewed release | Exact version |
| --- | --- |
| Antigravity CLI | 1.1.8 |

Antigravity 1.1.8 added the `json` and `stream-json` output modes required by
Ground's recognized adapter. The built-in preset therefore requires 1.1.8 or
newer. Discovery only resolves the executable and does not run it. After the user
confirms the native executable while saving, Ground revalidates it and runs a
bounded, shell-free `agy --version` probe; the locally installed 1.0.9 binary is
then rejected before the profile is persisted.

That review tightened the synthetic contract cases for Codex command progress,
declines, error items, and exact usage fields; Claude top-level tool-use/result
messages; Gemini warning/error severity; and added documented Antigravity
stream-envelope fixtures. It still does not establish real
stream ordering, authentication, permission enforcement, cancellation, or resume
continuity.

Google announced that, beginning June 18, 2026, Gemini CLI no longer serves Google
AI Pro, Ultra, or free individual accounts; enterprise licenses, Google Cloud, and
paid API-key access remain available. Individual users are directed to Antigravity
CLI. Ground therefore keeps Gemini CLI as a version-pinned enterprise/API-key
runtime and does not imply that an individual OAuth login can still run it. See
Google's [transition announcement](https://github.com/google-gemini/gemini-cli/discussions/27274).

## Not certified by this check

- No authenticated or paid model request was made.
- No filesystem or command action was requested from a CLI.
- The representative JSON event fixtures are explicitly marked
  `synthetic-contract` or `documented-example` and were not captured from these
  named binaries or releases.
- Windows and Linux invocation behavior was not exercised.

Before calling these versions supported, capture redacted event fixtures from
disposable accounts and repositories, review each vendor’s telemetry and
permission behavior, and run the full compatibility report described in
[Compatibility](../COMPATIBILITY.md).
